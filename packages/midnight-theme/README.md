# Midnight

**A quiet dark theme for long coding sessions.**

Graphite-blue backgrounds, soft contrast and a restrained palette: just enough color to read code at a glance, nothing that shouts.

## What it covers

- **Editor:** syntax colors, semantic highlighting, selections, find matches and bracket pairs.
- **Workbench:** sidebars, tabs, title bar, status bar, panels, menus, inputs and buttons.
- **Git:** gutter indicators, file decorations and diff editor.
- **Integrated terminal:** a full 16-color ANSI palette that matches the editor.
